# Code of Conduct

## Our standard

Everyone participating in this project is expected to make collaboration respectful, clear, and focused on the work. Critique technical ideas and evidence without attacking people.

Examples of helpful behavior include:

- Using welcoming, inclusive language.
- Giving specific, constructive feedback and accepting good-faith corrections.
- Respecting different experience levels and backgrounds.
- Protecting private information and obtaining permission before sharing someone else's data or work.

Unacceptable behavior includes harassment, threats, personal attacks, discriminatory language, deliberate disruption, or publishing private information without consent.

## Scope and enforcement

This standard applies to repository issues, pull requests, discussions, and other project spaces when someone is representing or participating in the project.

The maintainer may edit or remove harmful content, close discussions, or restrict participation when needed to keep project spaces usable. To report a conduct concern, contact the maintainer through the public GitHub profile and request a private channel. For security reports, follow [`SECURITY.md`](SECURITY.md).
