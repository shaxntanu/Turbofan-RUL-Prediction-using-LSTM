## Refreshing published results

Experiment outputs under outputs/ and models/ are local generated data. The static apps read committed files under web/public/results. After changing a result snapshot, regenerate the export, inspect the resulting JSON, CSV, and plots, run the local Markdown check and relevant tests, then commit the reviewed snapshot. A successful export only proves that files were written; it does not validate the methodology or make a stale study current.

For data provenance and paper scope, see [research-sources.md](research-sources.md). For runtime prerequisites and the distinction between local and hosted verification, see [compatibility.md](compatibility.md).
